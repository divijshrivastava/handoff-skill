Handoff setup

Ctrl+Alt+H is your friend

One shortcut opens the live Handoff dashboard from iTerm2, Cursor's integrated terminal, or a tmux-wrapped agent bar. This page walks you through installing it and practicing the chord.

What you are setting up

Handoff tracks unfinished work in a shared HANDOFF.md ledger. The dashboard shows tasks, agents, and progress while you work. The shortcut keeps it one keystroke away without typing into the running agent.

You need Git, Python 3.9+, and handoff-tui on your PATH. Copy the launcher from the skill once if you have not already.

Where will you press the shortcut?

Pick the terminal you use most. The install command changes slightly for Cursor.

On macOS, Ctrl+Alt+H is Control+Option+H.

Install the binding

Run this in a shell at your repository. It installs the shortcut and runs the CLI practice prompt.


          
        

        

          For tmux-wrapped agents, use
          HANDOFF_VIEWER_KEY=C-M-h handoff-tui --root … --codex
          instead of the iTerm2/Cursor installer.

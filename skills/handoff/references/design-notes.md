# Design notes and lineage

This skill is inspired by
[`mvanhorn/last30days-skill`](https://github.com/mvanhorn/last30days-skill),
especially its use of:

- an early preflight before substantive work;
- one runtime `SKILL.md` as the behavioral source of truth;
- deterministic helper commands for repeatable checks;
- named failure modes derived from observed agent mistakes;
- progressive disclosure into bundled references; and
- verification that checks the contract rather than relying on confident prose.

The handoff workflow, ledger schema, validator, examples, and wording are
original to this skill. No Last30Days research logic or source code is copied.
